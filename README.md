\# English Trainer — приложение для изучения английских слов (флешкарточки)



Учебный проект по веб-разработке



\## Описание проекта



Веб-приложение на Django, позволяющее создавать карточки (слово + перевод), объединять их в задания и тренироваться в двух режимах:  

\- английский → русский  

\- русский → английский  



Проект выполнен в рамках учебного задания.



\*\*Основной функционал:\*\*

\- Регистрация и аутентификация пользователей.

\- Создание, редактирование, удаление карточек (слово, перевод, категория).

\- Создание заданий — наборов карточек с названием и описанием.

\- Фильтрация карточек по категории при создании задания.

\- Тренировка: показ карточки (слово или перевод), ввод ответа, подсчёт правильных ответов.

\- Случайное задание: выбор N карточек из всех или из определённой категории.

\- Адаптивный интерфейс на Bootstrap 5.



\## Быстрый запуск (Windows)



Если у вас установлен Python и Git, вы можете запустить проект одним файлом:



1\. Скачайте или клонируйте репозиторий.

2\. В корне проекта (там, где лежит `manage.py`) дважды кликните по файлу \*\*`RUN.bat`\*\*.

3\. Следуйте инструкциям в консоли:

&#x20;  - Если суперпользователь отсутствует, скрипт предложит его создать.

&#x20;  - Если суперпользователь уже есть, можно пропустить создание нового.

4\. После запуска сервера откройте браузер по адресу `http://127.0.0.1:8000`.



> \*\*Примечание:\*\* скрипт автоматически создаст виртуальное окружение, установит зависимости из `requirements.txt`, применит миграции и запустит сервер. Для остановки сервера нажмите `Ctrl+C`.



\## Подробная ручная установка



Для ручного запуска, выполните следующие шаги:



1\. Клонировать репозиторий:

&#x20;  ```bash

&#x20;  git clone https://github.com/Carcosa-civ/english\_trainer.git

&#x20;  cd english\_trainer

Создать виртуальное окружение и активировать его:



bash

python -m venv venv

source venv/bin/activate   # для Linux/Mac

venv\\Scripts\\activate      # для Windows

Установить зависимости:



pip install -r requirements.txt

Применить миграции:



python manage.py migrate

(Опционально) Создать суперпользователя для доступа к админке:



python manage.py createsuperuser

Запустить сервер разработки:



python manage.py runserver

Открыть в браузере: http://127.0.0.1:8000



Корректное хранение секретов и токенов

Для загрузки секретов как переменных окружения используется библиотека python-dotenv.



Все секретные токены (например, SECRET\_KEY) должны быть спрятаны в коде за импортом. Для этого создайте в корне репозитория файл .env и добавьте в него пары «переменная-значение».



Файл .env нужно обязательно поместить в .gitignore!



Пример настройки для данного проекта

Установите python-dotenv:



pip install python-dotenv

Создайте в корне проекта (рядом с manage.py) файл .env со следующим содержимым:



SECRET\_KEY=django-insecure-8a^g#\_f4^2!9k@3b\&6e$w%x7c5v8b\*n\&m%p$l#q@1z2x3c4v5b6



В english\_trainer/settings.py добавлен код для загрузки переменных:



python

from dotenv import load\_dotenv

import os

BASE\_DIR = Path(\_\_file\_\_).resolve().parent.parent

dotenv\_path = os.path.join(BASE\_DIR, ".env")

load\_dotenv(dotenv\_path)

SECRET\_KEY = os.getenv('SECRET\_KEY')

Теперь секретный ключ хранится вне кода, что повышает безопасность проекта.
